# maxitshop - E-Commerce Platform Implementation Plan

## Goal
Build a high-performance, mobile-first e-commerce web application called "maxitshop" tailored for the Bangladesh market, matching the layout, structure, and visual hierarchy of https://bdshop.com/ with custom branding, BDT (৳) currency, Next.js frontend (Customer shop + Admin panel), and Express backend.

## Tech Stack
- Frontend: Next.js (App Router), TypeScript, Tailwind CSS, Lucide React Icons
- Backend: Node.js, Express, CORS, Dotenv
- Architecture: Decoupled Controller/Service/Data Layer ready for MongoDB Mongoose migration
- Ports: Backend on 5000, Frontend on 3000

## API Endpoints (/api/v1)
- GET /health - Service health check
- GET /categories - Category tree with subcategories
- GET /banners - Hero carousel banners
- GET /products - Paginated product list with search, category, brand, price filters, sorting
- GET /products/deals - Deals of the day
- GET /products/new - New arrivals
- GET /products/featured - Featured products
- GET /products/:slug - Product details with related products
- GET /search/suggestions?q= - Live search autocomplete suggestions
- POST /orders - Place new COD order with Dhaka/outside-Dhaka shipping calculation & stock decrement
- GET /orders/track?orderNumber=&phone= - Customer track order
- GET /admin/orders - Admin list all orders (Protected by ADMIN_TOKEN)
- PATCH /admin/orders/:id/status - Admin update order status (Protected by ADMIN_TOKEN)
- POST /admin/products - Admin create product (Protected by ADMIN_TOKEN)
- PUT /admin/products/:id - Admin update product (Protected by ADMIN_TOKEN)
- DELETE /admin/products/:id - Admin delete product (Protected by ADMIN_TOKEN)
